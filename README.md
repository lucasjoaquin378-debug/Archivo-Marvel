# Marvel Archive

Sitio estático independiente. No requiere base de datos ni instalación.

## Archivos
- `index.html`: estructura de la web.
- `style.css`: diseño adaptable a móvil y escritorio.
- `script.js`: catálogo, buscador, filtros y fichas emergentes.

## Publicar
Subí los tres archivos a la raíz de un repositorio de GitHub y luego importá ese repositorio desde Vercel. El proyecto es estático: no necesita comando de build ni directorio de salida.

## Editar el catálogo
Los títulos están en el array `ITEMS` al comienzo de `script.js`. Cada registro tiene universo, título, año, tipo, descripción y temporada (si corresponde).

Proyecto fan no oficial. Marvel y sus personajes pertenecen a sus respectivos titulares.
